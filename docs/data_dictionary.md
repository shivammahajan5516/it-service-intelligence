# Data dictionary – raw extract (`data/raw/`)

> **Synthetic data.** Generated by `scripts/generate_dataset.py` (seed 42). Extract snapshot:
> **2025-12-31 23:59:59**. Timestamps are `YYYY-MM-DD HH:MM:SS`, UK local time. Booleans are
> `true` / `false`. An empty field means NULL.
>
> "Req." marks a field that should never be empty in a correct record. "Opt." marks a field that
> can legitimately be empty. Known injected defects are listed in the DQ column. The full list is
> in `docs/06_synthetic_data_design.md`.
